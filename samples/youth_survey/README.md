# サンプルデータ：〇〇町 若年層意識調査（架空）

D2PATTの動きを試すための、架空のデータです。実在の自治体や調査の回答をもとにしたものではありません。分析の結果も架空のデータから出たもので、どこかの町の実態を表すものではありません。

## 中身

- `youth_survey.csv`：架空の〇〇町が、2026年6月に町内に住む15〜29歳へ行った意識調査の回答です。300人分、21問（回答ID・回答日・回答方法の列を含めて24列）。文字コードはUTF-8（BOM付き）です。
- `request.txt`：分析を依頼するときの依頼文の例です。

## 試し方

1. `youth_survey.csv` を、D2PATTフォルダ直下の `input` フォルダにコピーします。`input` に置いたファイルは分析を始めると案件フォルダへ移るので、移動ではなくコピーにしてください。
2. D2PATTフォルダでClaude Codeを起動し、`request.txt` の中身を貼り付けて送ります。
3. 最初に聞かれる2つの質問には、次のように答えると手早く試せます。
   - 個人情報や機密情報が含まれる懸念：「懸念なし」（架空のデータのため）
   - 外部データ調査：「不要」

あとは、D2PATTフォルダの `README.md` に書かれた手順と同じ流れで進みます。所要時間と利用量の目安も、`README.md` を参照してください。
